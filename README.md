# Cyberbullying-Detection-using-Social-Networks
A sentiment analysis-based machine learning project designed to detect cyberbullying and abusive behavior on social media platforms. The system analyzes social media text using a dataset of 10,000+ entries to identify offensive, profane, or threatening content in real time.
The project classifies detected text into severity levels — Green (Low Risk), Yellow (Moderate Risk), and Red (High Risk) — to indicate the intensity of harmful behavior. It also triggers real-time email alerts to parents or guardians when high-risk or threatening content is identified.

Features
  1. Sentiment analysis for cyberbullying detection
  2. Real-time classification of harmful content
  3. Severity-based alert system (Green, Yellow, Red)
  4 .Automated email notifications
  5. Social media text monitoring and analysis
     
Tech Stack:
Python, Flask, Machine Learning, Sentiment Analysis, HTML/CSS, MySQL.
